# Reference material

Models are built by hand from these public photographs (used as visual reference only, not embedded):

- Old Bridge, Makurdi: Wikimedia Commons, `The_1932_rail_bridge.jpg`, `River_Benue_(in_Makurdi_showing_OLD_Bridge).jpg`, `A_view_of_a_bridge.jpg`.
- Makurdi markets: Wikimedia Commons, `A_Banana_and_Plantain_depot.jpg`, `A_Tomatoes_shop.jpg`.
- Bridge facts: Wikipedia, "Old Bridge, Makurdi" (completed 1932, Sir William Arrol & Co., about 788 m between abutments).

The Commons market photos are labelled as Makurdi markets, not Wurukum specifically. Replace with Wurukum photos when available.
